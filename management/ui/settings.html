Proxy Listen Addresses

Where the filtering proxy accepts connections. Add multiple to bind several addresses/ports.

Format host:port. Examples: 0.0.0.0:8080 (all IPv4), [::]:8080 (all IPv6), [::1]:8080 (IPv6 localhost), 192.168.1.10:3128.
