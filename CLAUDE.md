## Commands

```bash
# Install (first time)
./install.sh          # Linux
install.bat           # Windows

# Run
./start.sh            # Linux — starts proxy (8080) + management UI (8000) in one terminal
start.bat             # Windows — opens two separate console windows

# Tests
.venv/bin/pytest tests/ -v

# Run single test file
.venv/bin/pytest tests/test_url_filter.py -v

# Management API only (for UI dev, with auto-reload)
.venv/bin/uvicorn management.api.main:app --reload --port 8000

# Proxy only
.venv/bin/mitmdump --set confdir=./certs --listen-port 8080 -s proxy/main.py

# Update site category blocklists
bash scripts/update_categories.sh

# DOH resolver diagnostics
.venv/bin/python scripts/doh_check.py
```

## Architecture

Two independent processes share the `policies/` directory on disk:

**Proxy** (`proxy/`) — mitmproxy with custom addons, runs on port 8080.
- `proxy/main.py` — registers all addons in execution order
- `proxy/addons/policy_router.py` — runs first on every request; loads `policies/*.json` and `config/settings.json`, matches source IP to a policy via CIDR, attaches `flow.metadata["policy"]`; hot-reloads on file change via `watchfiles`
- `proxy/addons/*.py` — each addon reads `flow.metadata["policy"]` and applies its component if enabled
- `proxy/block_page.py` — shared block-page renderer (Jinja2); records block events via `shared.logstore`

**Management** (`management/`) — FastAPI + static UI, runs on port 8000.
- `management/api/main.py` — FastAPI app with CORS middleware; auth middleware intercepts all non-public paths; mounts routes then serves `management/ui/` as static files
- `management/api/routes/policies.py` — CRUD for `policies/*.json`; the file is the source of truth
- `management/api/routes/settings.py` — reads/writes `config/settings.json`; handles password change
- `management/ui/` — no build step required; CDN-linked Alpine.js + Tailwind CSS

**Shared** (`shared/`) — used by both processes:
- `shared/models.py` — Pydantic v2 `Policy` (canonical schema) and `GlobalSettings`
- `shared/logstore.py` — SQLite log store (WAL mode); owns schema, writes, reads, aggregation, retention, and JSONL migration
- `shared/categories.py` — `CategoryStore` with lazy loading and 60-second mtime-check cache

## Key Design Decisions

- **Policy = JSON file**: one file per policy in `policies/`. File name = `{safe_policy_name}.json`. The proxy watches for file changes and hot-reloads without restart.
- **Source IP matching**: matched by specificity, most specific first — (1) exact single-IP match, (2) CIDR block match (longest/narrowest prefix wins), (3) catch-all (empty `source_ips`). Within a tier, policies are checked in alphabetical file order (first wins).
- **Addon execution order**: `policy_router` → `mitm_control` → `url_filter` → `doh_filter` → `safesearch` → `youtube_filter` → then response hooks: `text_classifier` → `image_classifier` → `request_logger`.
- **Allow-list short-circuits everything**: a match in `url_filter.allow` sets `flow.metadata["url_allowed"] = True`; all downstream addons check this flag and skip the flow.
- **MITM bypass**: done globally via `ctx.options.ignore_hosts` (regex), aggregated from all policies' `mitm.mode == "exclude"` lists. Per-source-IP TLS bypass is architecturally impossible in mitmproxy.
- **MITM passthrough (filtering skip)**: `mitm_control` sets `flow.metadata["mitm_passthrough"]` for include-mode non-listed sites and for User-Agent rules (`mitm.ua_mode` / `mitm.user_agents`, case-insensitive substring match). This can't un-intercept TLS — the User-Agent header isn't visible until after interception — it only causes filtering addons to skip the flow.
- **ML dependencies are optional**: `text_classifier` works without a model (keyword regex only); `image_classifier` gracefully skips if `nudenet` fails to import. ML model for text is at `models/text_classifier.joblib`.
- **IPv6 + IPv4-mapped IPv6**: `policy_router._client_addrs()` normalises `::ffff:192.168.x.x` to plain IPv4 so CIDR matching works transparently.

## Policy Schema

A `Policy` object (defined in `shared/models.py`) has these top-level fields:

```
name          str          Human-readable name
source_ips    list[str]    CIDR ranges / exact IPs this policy applies to (empty = catch-all)
mitm          MitmConfig
url_filter    UrlFilterConfig
doh           DohConfig
safesearch    SafeSearchConfig
youtube       YouTubeConfig
text_classifier  TextClassifierConfig
image_classifier ImageClassifierConfig
block_page    BlockPageConfig
```

Each sub-config has an `enabled` bool. All default to disabled (safe default: filtering off).

### UrlFilterConfig

```
enabled        bool
mode           "blacklist" | "whitelist"
block          list[str]   Patterns to block (exact, *.domain, or glob)
allow          list[str]   Patterns to allow (short-circuits all other filters)
categories     list[str]   Category names to block (from categories/ dir)
```

### MitmConfig

```
enabled        bool
mode           "exclude" | "include"
hosts          list[str]   Hosts for exclude (bypass TLS) or include (only intercept these)
ua_mode        "exclude" | "include"
user_agents    list[str]   UA substrings; exclude = skip filtering; include = only filter these
```

### YouTubeConfig

```
enabled           bool
mode              "blacklist" | "whitelist"
channels          list[str]   Channel IDs (UCxxxxx), @handles, or display names
block_comments    bool
block_sidebar     bool
```

### DohConfig

```
enabled           bool
providers         list[str]   DOH provider names to intercept
```

Supported providers: `nextdns`, `cloudflare`, `cleanbrowsing`, `adguard`. Detection uses NXDOMAIN, EDE codes 15/16/17, sinkhole IPs, and provider-specific block-page IPs.

## Authentication

`management/api/auth.py`:
- **Password hashing**: PBKDF2-SHA256, 200 000 iterations, 16-byte random salt. Hash stored in `config/settings.json` as `password_hash`.
- **Session token**: `HMAC-SHA256(secret_key, password_hash)` — survives server restarts; automatically invalidated when password changes (hash changes → token changes).
- `secret_key` is generated once and stored in settings when auth is first enabled.
- Public paths that bypass auth middleware: `/login.html`, `/api/login`, `/api/logout`, `/api/auth-status`, `/proxy.pac`, `/wpad.dat`, `/wpad.da`.

## PAC (Proxy Auto-Config)

`management/api/pac.py` generates dynamic PAC JavaScript at `/proxy.pac` and `/wpad.dat`.

Rules in order:
1. Plain hostnames (no dots) → `DIRECT`
2. Private/loopback ranges (10.x, 172.16–31.x, 192.168.x, 169.254.x, 127.x) → `DIRECT`
3. Hosts matching `pac_direct_hosts` setting (wildcard support) → `DIRECT`
4. Everything else → `PROXY <host>:<port>` (no DIRECT fallback — intentional)

The PAC response self-adapts the proxy address from the incoming request's `Host` header.

## Request/Block Logging

Logs are stored in **`logs/webfilter.db`** (SQLite, WAL mode). Two tables:
- **`requests`**: fields `ts`, `method`, `host`, `path`, `status`, `action`, `component`, `policy`, `client_ip`.
- **`blocks`**: fields `ts`, `domain`, `url`, `reason`, `component`, `policy`, `client_ip`.

Key behaviours:
- **Retention**: rows older than `log_retention_days` (default 30) are pruned automatically every 500 inserts and at proxy startup. Set to 0 to keep everything.
- **Migration**: on first proxy start after deploy, any existing `requests.jsonl` / `blocks.jsonl` are imported then renamed to `*.jsonl.imported` (non-destructive).
- **Concurrency**: proxy (single writer, one persistent connection + `threading.Lock`) and management API (read-only connections, one per call) coexist via WAL mode. Assumes `logs/` is on local disk — a network share would break WAL.
- **Export**: `GET /api/logs/export?kind=requests|blocks&format=csv|xlsx&start=<unix>&end=<unix>` streams a download. Capped at 500,000 rows.
- `flow.metadata["wf_action"]` and `flow.metadata["wf_component"]` carry the final decision through the addon chain to `request_logger`.

## Category Store

`shared/categories.py` — `CategoryStore`:
- Categories live in `categories/<name>/domains` (one domain per line).
- `categories/index.json` lists available categories with metadata.
- Loaded lazily; mtime checked every 60 seconds (not on every request).
- Matching is registrable-suffix based: host `a.b.example.com` is checked against `a.b.example.com`, `b.example.com`, and `example.com`.
- Global singleton `store` is imported by proxy addons.

## DOH Filter Details

`proxy/addons/doh_filter.py`:
- Intercepts `application/dns-message` (RFC 8484 wireformat) requests to configured providers.
- Sends both A and AAAA queries via async `httpx`.
- Detects blocked responses by: NXDOMAIN, EDE codes 15 (Blocked) / 16 (Censored) / 17 (Filtered), sinkhole IPs (`0.0.0.0`, `::`, `127.0.0.1`), and provider-specific block-page IPs (AdGuard: `94.140.14.35/36`, `2a10:50c0::bad1:ff`, `2a10:50c0::bad2:ff`).
- Caches responses with TTL (capped at 600 s); fails open after 30 s timeout.

## YouTube Filter Details

`proxy/addons/youtube_filter.py` (response hook):
- Intercepts 5 API endpoints: `/youtubei/v1/player`, `/youtubei/v1/get_watch`, `/youtubei/v1/next`, `/youtubei/v1/reel/reel_watch_sequence`, plus HTML `/watch` and `/shorts/` pages.
- Channel matching: exact channel ID (`UC…`), `@handle` (case-insensitive), or display name.
- In **blacklist** mode: blocks listed channels by rewriting `playabilityStatus.status` to `"ERROR"` and dropping `streamingData`.
- In **whitelist** mode: blocks any channel NOT in the allow-list.
- Optional: strip comments section, strip recommended sidebar, block home feed.

## Image Classifier Details

`proxy/addons/image_classifier.py`:
- Uses NudeNet 3.x (ONNX, CPU-only, no GPU required).
- Detects: `FEMALE_GENITALIA_EXPOSED`, `MALE_GENITALIA_EXPOSED`, `FEMALE_BREAST_EXPOSED`, `BUTTOCKS_EXPOSED`, `ANUS_EXPOSED`.
- Actions: `blur` (Gaussian, radius ∝ image size), `checkerboard` placeholder, or `block` (transparent 1×1 GIF).
- Skips images whose largest side is under `image_classifier.min_dimension` px (default 100) — favicons, icons, tracking pixels. Dimensions are read from the image header (PIL, no full decode); a 1 KB byte floor cheaply discards genuine pixels first. Gating on dimensions rather than byte size lets small-but-real thumbnails (e.g. Google image search, often ~2-8 KB) reach the detector.
- Requires `nudenet` package; addon silently skips if import fails.

## UI Development Notes

The UI (`management/ui/`) ships a pre-built `management/ui/tailwind.css` — no CDN dependency and no Node/npm toolchain required at runtime. Alpine.js is still loaded from CDN (jsdelivr). To iterate on the UI:

```bash
# Start the API with auto-reload
.venv/bin/uvicorn management.api.main:app --reload --port 8000
# Open http://localhost:8000 in a browser
```

Each HTML page is standalone; navigation is via `<a href>` links. Alpine.js `x-data` components handle API calls and reactive state.

### Rebuilding tailwind.css

If you add new Tailwind utility classes to any HTML file in `management/ui/`, regenerate the CSS with the Tailwind v3 standalone binary (no npm needed):

```powershell
# Windows
scripts\build_tailwind.ps1
```

```bash
# Linux / macOS
bash scripts/build_tailwind.sh
```

Both scripts download the standalone binary on first run (cached at `$env:TEMP\tailwindcss-v3.exe` / `~/.cache/tailwindcss/`) and skip re-downloading on subsequent runs. The build sources are:
- `management/ui/tailwind.config.js` — color palette config (mirrors the CSS variable map in `theme.css`)
- `management/ui/tailwind.input.css` — `@tailwind` directives + `@layer components` rules (`.badge`, `.bar-track`, `.bar-fill`, `.section`, `.section-header`, `.tag`)

## Common Conventions

- **New addon**: add the class to `proxy/addons/`, import and append to the list in `proxy/main.py`, follow the `flow.metadata` gate pattern (`url_allowed` / `mitm_passthrough`).
- **New policy field**: add the field to `shared/models.py` with a default value; the proxy picks it up on next policy reload; add a UI control in `management/ui/policy-editor.html`.
- **Safe policy name**: `re.sub(r"[^a-zA-Z0-9_\-]", "_", name)` — applied in `management/api/routes/policies.py` when creating files.
- **Block page**: call `block_page.make_block_response(flow, reason, component)` and `block_page.log_block(...)` then `return` from the addon hook.
- **Metadata keys**: `url_allowed` (bool), `mitm_passthrough` (bool), `wf_action` (str), `wf_component` (str), `policy` (Policy object).
